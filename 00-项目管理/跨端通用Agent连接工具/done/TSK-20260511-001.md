# [M1.1] 需求调研与场景分析

## 目标
明确目标用户画像、核心使用场景、功能边界，输出需求清单

## 任务说明
- 定义「跨端通用Agent连接工具」的目标用户
- 梳理核心使用场景与业务流程
- 确定功能边界（做什么、不做什么）
- 输出需求清单文档

## 验收标准
- [ ] 用户画像清晰（至少 2 类目标用户）
- [ ] 核心场景不少于 3 个
- [ ] 功能边界明确，有「不做什么」列表
- [ ] 输出需求清单，包含 P0/P1 优先级划分
