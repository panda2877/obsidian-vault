# [M1.2] 技术方案预研

## 目标
调研跨端方案（Web/PC）、通信协议、Agent 连接方式，对比技术选型

## 任务说明
- 调研 Web 端技术栈（SPA/SSR/WebSocket 等）
- 调研 PC 端技术栈（Electron/Tauri/Qt 等）
- 调研 Agent 连接协议（MCP/自定义协议/WebSocket 等）
- 对比各方案优劣，输出技术选型建议

## 验收标准
- [ ] Web 端技术选型不少于 2 种方案对比
- [ ] PC 端技术选型不少于 2 种方案对比
- [ ] Agent 通信协议调研覆盖主流方案
- [ ] 输出技术选型对比表

## 依赖
M1.1 需求清单（了解功能边界后才能精准选型）
