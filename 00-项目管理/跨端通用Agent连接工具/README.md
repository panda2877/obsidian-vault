# 跨端通用Agent连接工具

## 项目概述

跨端通用 Agent 连接工具（hermes-connect）：一套代码三端运行（Web / PC / 移动），作为 Hermes Agent 的官方跨端客户端。

## 技术架构

```
uni-app 前端 ──→ BFF 服务层（必选，8643） ──→ Hermes 层（8642）
                         │
                   Memory Service
                   （内嵌 LanceDB）
```

详见：[[docs/需求文档-v0.1|需求文档]] | [[docs/技术方案-v0.2|技术方案]] | [[docs/部署文档-v1.0|部署文档]]

## 设计风格

### 配色方案

#### 主色调
- **深色背景** `#0F0F10` - 主背景色，低调沉稳
- **卡片背景** `#18181B` - 卡片、面板背景
- **次级背景** `#27272A` - 输入框、hover态

#### 强调色
- **琥珀金** `#D4A853` - 主强调色，用于发送按钮、选中态、活跃项边框
- **在线绿** `#22C55E` - 连接状态指示

#### 文字色
- **主文字** `#FAFAFA` - 标题、主要内容
- **次级文字** `#A1A1AA` - 辅助说明、次要信息
- **占位符** `#71717A` - 输入框占位符

#### 边框色
- **分割线** `#3F3F46` - 卡片边框、分割线

### 设计特点
- 深色主题，适合长时间使用
- 琥珀金作为主强调色，传达温暖专业的品质感
- 卡片式布局，层次分明
- 圆角统一为8px，保持视觉一致性
