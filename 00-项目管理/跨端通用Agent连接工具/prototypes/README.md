# 聊天界面原型 v1 — 第一期功能

> 对应 M1.4 原型图绘制任务

## 涵盖的功能

| 功能 | 状态 | 说明 |
|------|------|------|
| 聊天消息列表 | ✅ | 用户气泡（紫色）/ Agent 气泡（深灰） |
| 流式回复指示器 | ✅ | 动态呼吸动画 + "Agent 正在思考..." |
| 多 Profile 切换 | ✅ | 左侧栏四个 Profile，点击切换 |
| 文件/图片上传 | ✅ | 工具栏按钮 + 上传预览条 |
| 富消息卡片 | ✅ | 代码块、图片嵌入、文件卡片、结构化卡片 |
| 消息时间戳 | ✅ | 每条消息下方显示时间 |
| 日期分隔线 | ✅ | 按天分组 |
| 输入框自动伸缩 | ✅ | 随内容增高，最大 120px |
| Enter 发送 | ✅ | Ctrl+Enter 换行 |
| 深色主题 | ✅ | 适配 Hermes 品牌色（紫色） |

## 交互操作

1. **点击左侧 Profile** → 切换聊天对象
2. **点击 📎 按钮** → 显示上传预览
3. **输入文字后点 ➤ 或按 Enter** → 模拟发送消息 + Agent 回复（1.5s 延迟）
4. **点击卡片按钮** → 可点击，有 hover 效果

## 查看方式

浏览器打开本文件即可，无需任何服务器。
