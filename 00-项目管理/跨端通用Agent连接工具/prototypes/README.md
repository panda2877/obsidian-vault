# 聊天界面原型 v2 — 完整功能版

> 对应 M1.4 原型图绘制任务
> 版本：v2.0

## 设计风格参考

参考 Hermes Workspace 仪表盘风格，采用深色模式 + 科技感设计语言。

### 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#0B1C19` | 极深墨绿/黑 |
| 侧边栏/面板背景 | `#0D211D` | 比主背景稍亮 |
| 卡片/区块背景 | `#122622` | 深青色墨绿 |
| 卡片边框 | `#1E3A32` | 微弱边框增加立体感 |
| 主文字 | `#E8E6D9` | 暖灰白 |
| 次要文字 | `#6B7D78` | 墨绿灰 |
| 强调色/高亮 | `#D4A853` | 琥珀金 |
| 辅助强调 | `#22C55E` | 荧光绿 |
| 紫色品牌色 | `#7C3AED` | Hermes 紫 |
| 危险/删除 | `#EF4444` | 红色 |

### 字体

- 主字体：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Noto Sans SC", sans-serif`
- 等宽字体：`'SF Mono', 'Fira Code', 'JetBrains Mono', monospace`
- 字号层级：11px(辅助) / 12px(状态) / 13px(次要) / 14px(正文) / 16px(标题) / 20px(大标题)

### 圆角与间距

- 卡片圆角：`8px`
- 按钮圆角：`6px`
- 输入框圆角：`8px`
- 间距基准：`4px` 倍数（4/8/12/16/20/24/32）

### 视觉语言

- 卡片有微弱顶部高光线条（`1px` 半透明边框）
- 选中态用琥珀金高亮线或紫色背景
- 图标使用线性风格（`stroke-width: 1.5`）
- 阴影使用深色半透明（`rgba(0,0,0,0.4)`）

## 功能清单

| 区域 | 功能 | 交互 |
|------|------|------|
| **Topbar** | Hermes Connect 品牌 + 状态指示 | 全局公用 |
| **Fn 栏** | Chat / Setting 图标 | 切换功能页面 |
| **Agent 栏** | Profile 列表 | 点击切换当前 Agent |
| **Message Header** | 记忆查看(可点击) / 搜索会话 / Session列表 | 点击展开辅助面板或浮窗 |
| **辅助面板** | 记忆查看(Tab: User/Soul/Memory) / Session列表 | 可收起，移动端浮窗 |
| **输入区** | 上传附件 / 新建会话(/new) / 发送 | 简化工具栏 |

## 移动端适配

- Agent 栏和 Message 栏分为两个独立页面（多级导航）
- 辅助面板使用浮窗（Modal/Drawer）模式
- 底部 Tab 切换 Agent 和 Message 视图
