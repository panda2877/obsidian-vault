> 版本：v2.1 | 更新：2026-05-12

## 设计风格参考

参考 Hermes Workspace 仪表盘风格，采用**墨绿深色主题** + 科技感设计语言。

### 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#0B1C19` | 极深墨绿/黑 |
| 侧边栏/面板背景 | `#0D211D` | 比主背景稍亮 |
| 卡片/区块背景 | `#122622` | 深青色墨绿 |
| 卡片边框 | `#1E3A32` | 微弱边框增加立体感 |
| 主文字 | `#E8E6D9` | 暖灰白 |
| 次要文字 | `#6B7D78` | 墨绿灰 |
| 强调色/高亮 | `#D4A853` | 琥珀金 |
| 辅助强调 | `#22C55E` | 荧光绿 |
| 紫色品牌色 | `#7C3AED` | Hermes 紫 |
| 危险/删除 | `#EF4444` | 红色 |

### 字体

- 主字体：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Noto Sans SC", sans-serif`
- 等宽字体：`'SF Mono', 'Fira Code', 'JetBrains Mono', monospace`
- 字号层级：10px(辅助) / 11px(状态) / 12px(次要) / 13px(正文) / 14px(标题) / 15px(大标题)

### 圆角与间距

- 卡片圆角：`8px`
- 按钮圆角：`6px`
- 输入框圆角：`8px`
- 间距基准：`4px` 倍数（4/8/12/16/20/24）

### 视觉语言

- 卡片有微弱边框增加立体感（`#1E3A32`）
- 选中态用琥珀金高亮线或紫色背景
- 图标使用 emoji 或线性风格
- 阴影使用深色半透明（`rgba(0,0,0,0.4)`）

## 功能清单

### Topbar（全局公用）

| 元素 | 功能 | 说明 |
|------|------|------|
| Logo + 标题 | 品牌标识 | ✦ Hermes Connect |
| 状态指示 | 连接状态 | 已连接 ● 端口 8642 |

### Fn 栏（功能切换）

| 元素 | 功能 | 说明 |
|------|------|------|
| 💬 聊天 | 切换到聊天视图 | 高亮显示当前视图 |
| ⚙ 设置 | 切换到设置视图 | 待实现 |

### Agent 栏（Agent 列表）

| 元素 | 功能 | 说明 |
|------|------|------|
| 列表项 | 点击切换 Agent | 显示在线状态 ● |
| 头像 | Agent 标识 | 圆形，带颜色区分 |

### Message Header（消息头部）

| 元素 | 功能 | 交互 |
|------|------|------|
| 当前 Agent 信息 | 显示当前聊天对象 | 头像 + 名称 + 在线状态 |
| 🧠 记忆已加载 | 点击查看记忆详情 | 展开辅助面板 |
| 🔍 搜索 | 浮窗搜索会话内容 | Ctrl+F 或点击图标 |
| 📋 Sessions | 切换会话 | 展开辅助面板显示会话列表 |

### 辅助面板（可收起）

| Tab | 内容 | 格式 |
|-----|------|------|
| User | User Profile | MD 格式预览 |
| Soul | Soul Definition | MD 格式预览 |
| Memory | LanceDB 记忆列表 | 卡片列表 |
| Sessions | 可切换的会话列表 | 点击切换 |

### 输入区

| 元素 | 功能 | 说明 |
|------|------|------|
| 📎 上传 | 上传附件 | 保留 |
| ➕ 新建 | 创建新会话 | /new 命令 |
| [输入框] | 消息输入 | Ctrl+Enter 发送 |
| ➤ 发送 | 发送消息 | 紫色品牌色 |

## 移动端适配

### 布局调整

| 断点 | 适配策略 |
|------|----------|
| ≤ 768px | 隐藏 Fn 栏和 Agent 栏 |

### 多级导航

- Agent 栏和 Message 栏分为两个独立页面
- 底部 Tab 切换：Agent → 聊天 → 辅助

### 辅助面板

- 使用浮窗/Drawer 模式
- 从右侧滑入
- 宽度：`85%` 或 `320px`

## 交互规范

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl + Enter | 发送消息 |
| Ctrl + F | 打开搜索 |
| Escape | 关闭浮窗/搜索 |

### 动画过渡

| 元素 | 动画 | 时长 |
|------|------|------|
| 辅助面板收起/展开 | width + opacity | 300ms ease |
| 浮窗显示/隐藏 | opacity | 200ms |
| 按钮 hover | background + transform | 200ms |
| 输入框 focus | border-color | 200ms |
