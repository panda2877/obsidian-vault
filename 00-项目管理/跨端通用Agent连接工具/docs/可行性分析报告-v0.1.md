| ID | 功能 | 实现方式 | 难度 | 预估工时 |

| F-003 | 消息列表（虚拟滚动） | uni-app 虚拟列表组件 | 🟢 低 | 1 天 |

| F-008 | 基础工程搭建 | uni-app 初始化 + Tauri 集成 | 🟢 低 | 1 天 |

> **关键发现：api_server 已在端口 8642 上运行。** 零配置，前端直接调。

### 2.2 P1 功能 — 全部可行 ✅

| ID | 功能 | 实现方式 | 难度 | 预估工时 |
|----|------|----------|------|---------|
| F-101 | Tauri PC 桌面端 | uni-app H5 产物 + Tauri 壳打包 | 🟢 低 | 2 天 |
| F-102 | PWA 移动端 | manifest.json + Service Worker | 🟢 低 | 1 天 |
| F-103 | 会话历史管理 | 前端本地存储 + Hermes Session DB | 🟡 中 | 2 天 |
| F-104 | 消息格式增强 | Markdown 渲染库 + 代码高亮 | 🟢 低 | 1 天 |
| F-105 | 主题切换 | CSS 变量 + 亮色/暗色模式 | 🟢 低 | 1 天 |

### 2.3 P2 功能 — 基本可行，需 BFF 支撑

| ID | 功能 | 实现方式 | 难度 | 说明 |
|----|------|----------|------|------|
| F-201 | 记忆浏览器 | BFF 内嵌 Memory Service，封装 LanceDB 接口 | 🟡 中 | BFF MVP 阶段必选，统一管理记忆 |
| F-202 | 看板管理面板 | 需 BFF 包装看板 CRUD 接口 | 🟡 中 | 同上 |
| F-203 | Profile 管理 | 需 BFF 包装配置读写 | 🟡 中 | 同上 |
| F-204 | Agent 注册表 | 需 BFF 包装 agent_registry 查询 | 🟡 中 | 同上 |
| F-205 | BFF 后端 | Python FastAPI，30-50 MB | 🟢 低 | **MVP 阶段必选**，内嵌 Memory Service |

> P2 功能需要 BFF 层。BFF 服务层为**必选**组件，MVP 阶段即部署。Memory Service 内嵌于 BFF，统一管理记忆数据。LanceDB 未来逐步从 Hermes 剥离。

### 2.4 不可实现 / 暂不考虑

| 功能 | 原因 | 替代方案 |
|------|------|----------|
| 原生 iOS/Android App（非 PWA） | MVP 阶段不必要 | 先用 PWA，后续 uni-app 一键编译 |
| Agent 主动推送通知 | 需要额外推送服务器 | MVP 后迭代 |
| 多人协作/多用户 | 个人工具，非目标 | 开源后社区可扩展 |
