### 1.2 版本管理

**统一版本策略**：
- 版本号定义在仓库根目录 `VERSION` 文件
- Git tag 使用 `v` 前缀：`v1.0.0`、`v1.1.0`
- 所有组件（frontend、bff）使用同一版本号
- 可独立构建、独立部署，但版本同步

```
# VERSION 文件内容
1.0.0
```

### 1.3 Git 标签规范

```bash
# 整体发布（frontend + bff 一起）
git tag v1.0.0
git push origin v1.0.0

# 未来独立发布（可选）
git tag frontend-v1.0.1
git tag bff-v1.0.1
```

## 2. 版本策略详解

### 2.1 版本号规则

采用语义化版本（SemVer）：
```
主版本.次版本.修订版本
  v1.0.0
```

| 变更类型 | 触发条件 | 版本升级 |
|----------|----------|----------|
| **主版本** | 架构重大调整、BFF API 不兼容 | 1.0.0 → 2.0.0 |
| **次版本** | 新功能、向后兼容的 BFF API 变更 | 1.0.0 → 1.1.0 |
| **修订版本** | Bug 修复、文档更新、小幅优化 | 1.0.0 → 1.0.1 |

### 2.2 版本与构建产物

每次 Git tag 触发 CI 构建，生成独立的部署包：

```
hermes-connect-v1.0.0/
├── hermes-connect-frontend.zip    # 前端静态文件（可部署到 CDN/Nginx）
└── hermes-connect-bff.tar.gz       # BFF 源码包（含 Docker 镜像定义）
```

### 2.3 独立部署场景

| 场景 | 前端版本 | BFF 版本 | 说明 |
|------|----------|----------|------|
| 一起发版 | v1.0.0 | v1.0.0 | 常规发布 |
| 前端热更新 | v1.0.1 | v1.0.0 | 只更新前端静态资源 |
| BFF 紧急修复 | v1.0.0 | v1.0.1 | 只更新 BFF 服务 |
| 架构升级 | v2.0.0 | v2.0.0 | 主版本升级，需一起更新 |

## 3. 构建流程

### 3.1 构建脚本

```bash
# scripts/build.sh
#!/bin/bash
set -e

VERSION=$(cat VERSION)
DIST_DIR="dist/hermes-connect-${VERSION}"
mkdir -p "$DIST_DIR"

echo "=== Building hermes-connect v${VERSION} ==="

# 构建前端
echo "[1/2] Building frontend..."
cd frontend
npm install
npm run build:h5
cd ..

# 构建 BFF
echo "[2/2] Building BFF..."
cd bff
pip install -r requirements.txt -t ./dist_packages
python -m PyInstaller --onefile --name bff app/main.py
cd ..

# 打包
echo "[3/3] Packaging..."
cp -r frontend/dist "$DIST_DIR/frontend"
cp bff/dist/bff "$DIST_DIR/bff"
cp scripts/start.sh "$DIST_DIR/"
tar -czf "hermes-connect-${VERSION}.tar.gz" -C dist "hermes-connect-${VERSION}"

echo "=== Build complete: dist/hermes-connect-${VERSION}.tar.gz ==="
```

### 3.2 CI/CD 流水线（GitHub Actions 示例）

```yaml
# .github/workflows/release.yml
name: Release

on:
  push:
    tags:
      - 'v*'

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Build Frontend
        run: |
          cd frontend
          npm install
          npm run build:h5

      - name: Build BFF
        run: |
          cd bff
          pip install -r requirements.txt
          pyinstaller --onefile app/main.py

      - name: Package
        run: |
          VERSION=${GITHUB_REF#refs/tags/v}
          mkdir -p dist
          cp -r frontend/dist dist/frontend
          cp bff/dist/main dist/bff
          tar -czf dist/hermes-connect-${VERSION}.tar.gz -C dist hermes-connect-${VERSION}

      - name: Upload Release
        uses: softprops/action-gh-release@v1
        with:
          files: dist/hermes-connect-*.tar.gz
```

### 4.2 部署模式

| 模式 | 适用场景 | BFF 部署 | 前端部署 |
|------|----------|----------|----------|
| **模式 A：一体部署** | 开发/测试/单人使用 | Hermes 服务器 | 同服务器 Nginx |
| **模式 B：分离部署** | 生产环境、安全隔离 | Hermes 服务器 | CDN / 独立 Nginx |
| **模式 C：客户端分发** | 开源用户、离线使用 | 本地启动 | Tauri 桌面端 |

### 4.3 模式 A：一体部署（开发/测试）

```bash
# 在 Hermes 服务器上
./start.sh

# 启动内容：
# 1. BFF 服务（端口 8643）
# 2. Nginx（端口 80，托管前端静态文件）
# 3. 前端开发服务器（可选，端口 8080）
```

### 4.4 模式 B：分离部署（生产）

```
Hermes 服务器：
  ├── Hermes Gateway（8642）
  ├── BFF（8643，仅内部访问）
  └── 不暴露 8643 端口到外网

前端服务器/Nginx：
  ├── 前端静态文件（/）
  └── 反向代理到 Hermes 服务器的 BFF（/api/ → 8643）

防火墙：
  - 仅开放 80/443（前端）
  - BFF 端口（8643）仅对内网/前端服务器开放
```

### 4.5 模式 C：Tauri 桌面端

```
用户本地：
  ├── Tauri 应用（内置前端）
  ├── 配置 BFF 地址（默认：http://localhost:8643）
  └── 首次启动时引导配置服务器地址
```

## 5. 启动脚本

### 5.1 主启动脚本

```bash
#!/bin/bash
#
# hermes-connect 启动脚本
# 用法：./start.sh [dev|prod]
#

set -e

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
VERSION=$(cat "$SCRIPT_DIR/VERSION" 2>/dev/null || echo "dev")

echo "=== Starting hermes-connect v${VERSION} ==="

# 检查 Python 环境
if ! command -v python3 &> /dev/null; then
    echo "❌ Python3 not found"
    exit 1
fi

# 启动 BFF
echo "[1/3] Starting BFF (port 8643)..."
cd "$SCRIPT_DIR/bff"
python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8643 &
BFF_PID=$!
echo "  BFF started (PID: $BFF_PID)"

# 启动前端开发服务器（开发模式）
if [ "$1" == "dev" ]; then
    echo "[2/3] Starting frontend dev server (port 8080)..."
    cd "$SCRIPT_DIR/frontend"
    npm run dev:h5 -- --port 8080 &
    FRONTEND_PID=$!
    echo "  Frontend started (PID: $FRONTEND_PID)"
fi

# 等待启动完成
echo "[3/3] Checking services..."
sleep 2

# 健康检查
if curl -s http://localhost:8643/health > /dev/null; then
    echo "✅ BFF is running at http://localhost:8643"
else
    echo "❌ BFF health check failed"
fi

if [ "$1" == "dev" ]; then
    echo "✅ Frontend available at http://localhost:8080"
fi

echo ""
echo "=== hermes-connect started ==="
echo "  BFF:       http://localhost:8643"
echo "  Frontend:  http://localhost:8080 (dev mode)"
echo "  Press Ctrl+C to stop"

# 保存 PID 以便后续停止
echo "$BFF_PID" > "$SCRIPT_DIR/.bff.pid"
[ "$1" == "dev" ] && echo "$FRONTEND_PID" > "$SCRIPT_DIR/.frontend.pid"

# 等待信号
wait
```

### 5.2 停止脚本

```bash
#!/bin/bash
#
# hermes-connect 停止脚本
#

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"

echo "=== Stopping hermes-connect ==="

# 停止 BFF
if [ -f "$SCRIPT_DIR/.bff.pid" ]; then
    BFF_PID=$(cat "$SCRIPT_DIR/.bff.pid")
    if kill -0 "$BFF_PID" 2>/dev/null; then
        kill "$BFF_PID"
        echo "✅ BFF stopped (PID: $BFF_PID)"
    fi
    rm "$SCRIPT_DIR/.bff.pid"
fi

# 停止前端
if [ -f "$SCRIPT_DIR/.frontend.pid" ]; then
    FRONTEND_PID=$(cat "$SCRIPT_DIR/.frontend.pid")
    if kill -0 "$FRONTEND_PID" 2>/dev/null; then
        kill "$FRONTEND_PID"
        echo "✅ Frontend stopped (PID: $FRONTEND_PID)"
    fi
    rm "$SCRIPT_DIR/.frontend.pid"
fi

echo "=== hermes-connect stopped ==="
```

## 7. Docker 部署（可选）

### 7.1 BFF Dockerfile

```dockerfile
# bff/Dockerfile
FROM python:3.11-slim

WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY app/ ./app/

EXPOSE 8643

CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8643"]
```

### 7.2 Docker Compose（完整部署）

```yaml
# docker-compose.yml
version: '3.8'

services:
  bff:
    build: ./bff
    ports:
      - "8643:8643"
    environment:
      - HERMES_API_URL=http://host.docker.internal:8642
      - HERMES_API_TOKEN=${HERMES_API_TOKEN}
    network_mode: host  # 与 Hermes 同一网络

  frontend:
    image: nginx:alpine
    ports:
      - "80:80"
    volumes:
      - ./frontend/dist:/usr/share/nginx/html:ro
      - ./nginx.conf:/etc/nginx/conf.d/default.conf:ro
    depends_on:
      - bff
```

## 8. 故障排查

### 8.1 常见问题

| 问题 | 检查项 | 解决方案 |
|------|--------|----------|
| BFF 启动失败 | 端口 8643 是否被占用 | `lsof -i :8643`，杀掉占用进程 |
| 前端无法连接 BFF | BFF 健康检查 | `curl http://localhost:8643/health` |
| 版本不匹配 | 检查 VERSION 文件 | 确保 frontend 和 bff 使用同一版本 |
| Hermes 连接失败 | api_server 是否运行 | `curl http://localhost:8642/health` |

### 8.2 日志位置

```
# BFF 日志
bff/logs/bff.log

# Nginx 日志（前端）
/var/log/nginx/access.log
/var/log/nginx/error.log
```
