## 三、systemd service 配置

每个 profile 对应一个 systemd user service。

**配置模板：**
```ini
# ~/.config/systemd/user/hermes-gateway-{name}.service
[Unit]
Description=Hermes Agent Gateway - {Name} Profile
After=network.target

[Service]
Type=simple
Environment=HERMES_HOME=/home/agentuser/.hermes/profiles/{name}
ExecStart=/home/agentuser/.hermes/hermes-agent/venv/bin/python -m hermes_cli.main gateway run --replace
Restart=always
RestartSec=5
MemoryMax=2G
CPUQuota=200%

[Install]
WantedBy=default.target
```

**管理命令：**
```bash
# 重新加载配置
systemctl --user daemon-reload

# 启动/重启/查看状态
systemctl --user start/restart/status hermes-gateway-{name}

# 查看日志
journalctl --user -u hermes-gateway-{name} -f
```

**已存在的 service：**
- `hermes-gateway.service`（银月）
- `hermes-gateway-xingruyin.service`（如音）
- `hermes-wensiyue.service`（❌ 思月，尚未创建）

## 四、启动步骤（实测）

### 1. 验证当前进程状态

```bash
# 查看所有 gateway 进程
ps aux | grep hermes_cli.main | grep gateway

# 验证 HERMES_HOME
for pid in $(pgrep -f "hermes_cli.main.*gateway"); do
  echo "PID $pid: $(cat /proc/$pid/environ | tr '\0' '\n' | grep HERMES_HOME)"
done
```

### 2. 重启单个 profile

```bash
# 重启如音（如修改配置后）
systemctl --user restart hermes-gateway-xingruyin

# 启动思月（目前是手动进程，需先创建 systemd service）
HERMES_HOME=/home/agentuser/.hermes/profiles/wensiyue \
  /home/agentuser/.hermes/hermes-agent/venv/bin/python -m hermes_cli.main gateway run --replace &
```

### 3. 验证是否成功

```bash
# 等待几秒后检查
sleep 5

# 检查进程是否存活
ps aux | grep hermes_cli.main | grep "wensiyue\|xingruyin"

# 检查飞书连接状态
cat ~/.hermes/profiles/wensiyue/gateway_state.json
cat ~/.hermes/profiles/xingruyin/gateway_state.json
```

## 五、已知问题与排查

### 问题1：飞书 app_id 冲突

**症状：**
```
Gateway hit a non-retryable startup conflict: feishu: Another local Hermes gateway is already using this Feishu app_id (PID xxx)
```

**原因：**
- 两个 profile 配置了相同的 `FEISHU_APP_ID`
- 思月的 `.env` 最初被错误配置为如音的 app_id

**解决：**
1. 确认每个 profile 的 `.env` 使用独立的飞书 app_id
2. 重启报错的 gateway

**验证：**
```bash
cat ~/.hermes/profiles/wensiyue/.env | grep FEISHU_APP_ID
cat ~/.hermes/profiles/xingruyin/.env | grep FEISHU_APP_ID
# 两个值必须不同
```

### 问题2：微信 token 冲突

**症状：**
```
Weixin bot token already in use (PID xxx). Stop the other gateway first.
```

**原因：**
- 微信 bot token 只能被一个 gateway 进程使用

**解决：**
- 暂时忽略，如音和思月用飞书通信
- 只有银月的 gateway 连接微信

### 问题3：gateway_state.json 显示旧 PID

**症状：**
- `gateway_state.json` 中的 PID 已不存在
- 但进程实际在运行

**原因：**
- gateway_state.json 是启动时的快照，不会实时更新

**解决：**
- 以实际进程状态为准
- 用 `ps aux | grep hermes_cli.main` 验证

### 问题4：重启后银月失忆

**现象：** 重启 gateway 后，银月不记得之前干了什么。

**缓解措施：** 重要操作前主动更新 memory 记录当前任务进度。
