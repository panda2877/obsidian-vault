## 三、启动步骤

### 1. 清理僵尸进程

**如音的僵尸进程（PID 1212796）需要先清理：**
```bash
kill -9 1212796
```

### 2. 逐一启动验证

按以下顺序启动，避免并发冲突：

```bash
# 先启动紫灵（app_id 独立）
hermes gateway run --profile ziling --replace

# 再启动思月
hermes gateway run --profile wensiyue --replace

# 最后启动如音（等思月验证完再动）
hermes gateway run --profile xingruyin --replace
```

### 3. 验证是否成功

每个启动后，检查进程是否存活：
```bash
ps aux | grep "hermes.*profile"
```

检查日志是否有报错：
```bash
tail -100 ~/.hermes/profiles/{profile}/logs/gateway.log
```

## 四、已知问题

### 问题1：重启后银月失忆

**现象：** 重启 gateway 后，银月不记得之前干了什么。

**缓解措施：** 重要操作前主动更新 memory 记录当前任务进度。

**改进计划：** 研究三层记忆机制（session、memory、context），预计今天 22:00 前完成。

### 问题2：各姐妹任务状态同步

**现象：** A agent 对 B agent 做操作时，不知道 B 在干啥。

**缓解措施：** 重要操作前通过消息传递确认对方状态；操作完成后回写结果到银月 memory 统一登记。
