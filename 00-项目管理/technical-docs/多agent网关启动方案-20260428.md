## 三、启动步骤

### 1. 清理僵尸进程

**如音的僵尸进程（PID 1212796）需要先清理：**
```bash
kill -9 1212796
```

### 2. 逐一启动验证

按以下顺序启动，避免并发冲突：

```bash
# 先启动紫灵（app_id 独立）
hermes gateway run --profile ziling --replace

# 再启动思月
hermes gateway run --profile wensiyue --replace

# 最后启动如音（等思月验证完再动）
hermes gateway run --profile xingruyin --replace
```

### 3. 验证是否成功

每个启动后，检查进程是否存活：
```bash
ps aux | grep "hermes.*profile"
```

检查日志是否有报错：
```bash
tail -100 ~/.hermes/profiles/{profile}/logs/gateway.log
```

## 四、已知问题

### 问题1：如音和思月 app_id 冲突

**现象：** 两个 profile 共用 `cli_a965e85a6f4b9bdd`，飞书同时只允许一个在线。

**解决思路：** 需要给其中一个申请新的飞书应用，或确认哪个是废弃的。

### 问题2：重启后银月失忆

**现象：** 重启 gateway 后，银月不记得之前干了什么。

**缓解措施：** 重要操作前主动更新 memory 记录当前任务进度。
