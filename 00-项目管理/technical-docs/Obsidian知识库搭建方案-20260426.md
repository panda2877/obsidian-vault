## 3. 可行性分析

### 3.1 服务器安装 Obsidian（无头模式）

**结论：✅ 可行**

**分析：**

Obsidian 提供 `obsidian-headless` 模式，适合无 GUI 的服务器环境：

```bash
# 环境要求
- Node.js 22+
- npm

# 安装方式
npm install -g obsidian-headless

# 登录 Obsidian 账户（需 Sync 订阅）
ob login --email <email> --password '<password>'

# 创建远程 Vault
ob sync-create-remote --name "Team Knowledge Base"

# 连接本地目录
cd ~/obsidian-vault
ob sync-setup --vault "<vault-id>"
```

**替代方案（无需 Obsidian 账户）：**

若不想使用 Obsidian Sync，可采用纯 Git 方案：
- 服务器初始化 Git 仓库
- PC 端使用 obsidian-git 插件
- 通过 GitHub/Gitea 中转

**风险点：**
- obsidian-headless 依赖 Node.js 22+，需确认服务器 Node 版本
- obsidian-headless 官方仍在迭代，部分功能可能不稳定

**建议：** 优先使用 obsidian-git 插件方案，社区成熟度高。

### 3.3 Git 同步方案可行性

**结论：✅ 可行，多种方案可选**

#### 方案 A：obsidian-git 插件（推荐）

**架构：**
```
PC (Obsidian + obsidian-git) ←→ GitHub ←→ 服务器 (bare repo)
```

**服务器端设置：**

```bash
# 在服务器创建裸仓库（作为中转）
mkdir -p ~/git/obsidian-vault.git
cd ~/git/obsidian-vault.git
git init --bare

# 在服务器创建工作仓库
mkdir -p ~/obsidian-vault
cd ~/obsidian-vault
git init
git remote add origin ~/git/obsidian-vault.git
```

**PC 端设置：**
1. 安装 Obsidian
2. 安装 obsidian-git 插件
3. 克隆仓库：`git clone 服务器IP:~/git/obsidian-vault.git ~/Obsidian/Vault`
4. 配置插件自动同步间隔（如 5 分钟）

**优点：** 社区成熟，配置简单
**缺点：** 需要服务器可 SSH 访问

#### 方案 B：GitHub Actions 自动同步

**架构：**
```
服务器 Git → GitHub → PC
```

**流程：**
1. 服务器本地 Git 仓库配置 GitHub remote
2. 通过 cron 或 webhook 触发 push
3. PC 端通过 obsidian-git 或官方 Sync 拉取

**优点：** 不需要服务器 SSH 暴露
**缺点：** 同步时效性较低

#### 方案 C：GitHub + 服务器定时 Pull（无 obsidian-git）

**服务器定时任务：**
```bash
# crontab -e
*/15 * * * * cd ~/obsidian-vault && git pull origin main >> /tmp/obsidian-sync.log 2>&1
```

### 3.5 新姐妹 Skill 定位（学习内容归纳）

**结论：✅ 建议创建**

**定位：**

基于 llm-wiki，针对「学习」场景的增强 skill：

| 维度 | llm-wiki（基础） | 新姐妹（学习版） |
|------|----------------|-----------------|
| 场景 | 通用知识积累 | 学习内容归纳 |
| 触发 | 任意知识库操作 | 团队成员添加学习资料 |
| 入口 | 手动指定来源 | 监听目录或接收指令 |
| 输出 | 完整 wiki 页面 | 学习笔记、摘要、问答 |
| 侧重点 | 知识体系化 | 快速掌握要点 |

**功能设计：**

1. **学习资料入口**
   - 监听 `~/obsidian-vault/01-学习/inbox/` 目录
   - 接收新文章链接、PDF、笔记

2. **内容归纳流程**
   - 读取原始资料
   - 生成摘要（50字内）
   - 提取关键知识点
   - 建立与现有知识的链接
   - 归档到 `concepts/` 或 `entities/`

3. **交互模式**
   - 银月/如音/思月/紫灵可 @ 触发
   - 支持「帮我归纳这个链接」
   - 支持「我刚学了 X，帮我更新知识库」

**与银月的分工：**

| 角色 | 职责 |
|------|------|
| 银月 | 发送资料给新姐妹 |
| 新姐妹 | 归纳资料，更新学习知识库 |
| 银月 | 定期查阅归纳结果 |
