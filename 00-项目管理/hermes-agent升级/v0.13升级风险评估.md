#### v0.13 新架构要点

- `MemoryProvider` (ABC)：抽象基类，要求实现：
  - `name` — 短标识符（如 `'builtin'`, `'honcho'`, `'lancedb'`）
  - `is_available()` — 检查配置/凭据/依赖是否就绪（不应做网络调用）
  - `initialize(session_id, **kwargs)` — 初始化连接、创建资源
  - `system_prompt_block()` — 返回要注入 system prompt 的静态文本
  - `prefetch(query, session_id)` — 每轮前 background recall，返回格式化文本
  - `queue_prefetch(query, session_id)` — 每轮后排队下次 prefetch
  - `sync_turn(user, asst, session_id)` — 每轮后持久化
  - `get_tool_schemas()` — 返回要暴露给模型的 tool 定义
  - `handle_tool_call(tool_name, args)` — 处理 tool 调用
  - `shutdown()` — 清理资源
- `MemoryManager`：统一编排入口，**只允许一个外部 provider 同时运行**
- `plugins/memory/` 目录：内置多个 provider — honcho, hindsight, mem0, retaindb, supermemory, byterover, holographic, openviking
- **没有 LanceDB 官方插件** — 我们的 LanceDB 实现是独特的

#### 迁移方案（详细步骤）

**步骤 1：创建插件目录结构**

```
plugins/memory/lancedb/
├── __init__.py          # LanceDBProvider 类实现
└── config.py            # LanceDB 配置加载（复用现有 lancedb_client 逻辑）
```

**步骤 2：实现 `LanceDBProvider` 类（参考 honcho 插件模式）**

```python
"""LanceDB memory plugin — MemoryProvider for LanceDB Memory Service."""

from __future__ import annotations

import logging
from typing import Any, Dict, List, Optional

from agent.memory_provider import MemoryProvider
from agent.lancedb_client import (
    fetch_soul, fetch_user, fetch_memories,
    search_memories, is_api_available
)

logger = logging.getLogger(__name__)


class LanceDBProvider(MemoryProvider):
    """LanceDB Memory Provider — replaces memory_tool.py load_from_disk()."""

    @property
    def name(self) -> str:
        return "lancedb"

    def is_available(self) -> bool:
        """Check if LanceDB API is reachable."""
        return is_api_available()

    def initialize(self, session_id: str, **kwargs) -> None:
        """Initialize — warm up connection."""
        hermes_home = kwargs.get("hermes_home", "")
        agent_identity = kwargs.get("agent_identity", "")
        agent_context = kwargs.get("agent_context", "primary")

        # Skip writes for non-primary contexts
        if agent_context != "primary":
            logger.debug("LanceDBProvider: skipping init for context=%s", agent_context)
            return

        # Warm up: test connection
        if not is_api_available():
            logger.warning("LanceDB API unavailable at init for agent=%s", agent_identity)

    def system_prompt_block(self) -> str:
        """Return static text for system prompt (e.g., provider status)."""
        # Optional: return status info like "Memory backend: LanceDB (connected)"
        return ""

    def prefetch(self, query: str, *, session_id: str = "") -> str:
        """Recall relevant context before each turn. Fast — use cached results."""
        agent_identity = session_id  # or get from kwargs
        if not agent_identity:
            return ""

        # Fetch memories for this agent
        entries = fetch_memories(agent_identity)
        if not entries:
            return ""

        # Format as context block (v0.13 uses <memory-context> tags)
        context_parts = []
        for i, entry in enumerate(entries[-10:], 1):  # last 10 memories
            context_parts.append(f"[Memory {i}]\n{entry}")

        return "\n\n".join(context_parts)

    def queue_prefetch(self, query: str, *, session_id: str = "") -> None:
        """Queue background prefetch for next turn — no-op for now."""
        pass

    def sync_turn(self, user_content: str, assistant_content: str, *, session_id: str = "") -> None:
        """Persist a completed turn — no-op for read-only LanceDB provider."""
        # Our current LanceDB is read-only; sync is handled externally
        pass

    def get_tool_schemas(self) -> List[Dict[str, Any]]:
        """Expose memory search tool."""
        return [
            {
                "name": "search_memories",
                "description": "Semantic search over stored memories.",
                "parameters": {
                    "type": "object",
                    "properties": {
                        "query": {"type": "string", "description": "Search query"},
                        "limit": {"type": "integer", "default": 5, "description": "Max results"},
                    },
                    "required": ["query"],
                },
            }
        ]

    def handle_tool_call(self, tool_name: str, args: Dict[str, Any], **kwargs) -> str:
        """Handle tool calls."""
        import json
        if tool_name == "search_memories":
            results = search_memories(
                args.get("query", ""),
                owner=kwargs.get("agent_identity"),
                limit=args.get("limit", 5)
            )
            return json.dumps({"results": results})
        raise NotImplementedError(f"Unknown tool: {tool_name}")

    def shutdown(self) -> None:
        """Clean shutdown — no-op for HTTP-based provider."""
        pass
```

## 三、v0.13 新功能详解

### 3.1 `/goal` — 持久跨轮目标（Ralph Loop）

**这是什么？**

`/goal` 是一个新的 slash 命令，让 agent 锁定一个长期目标，在多个对话轮次中持续跟踪和推进，不会"忘记"之前被分配的任务。

**典型场景：**

```
老大：/goal 帮我整理本周所有待办事项，汇总成一份周报
（agent 开始工作，可能分多轮完成：先查看板 → 再查邮件 → 再整理格式 → 最后输出）
（中间老大插入了其他对话）
（几轮后，agent 仍然记得 `/goal` 的目标，继续推进周报整理）
```

**核心机制：**
- 目标持久化存储（跨 session）
- 每轮自动检查目标进度
- 有 turn budget（轮次预算），防止无限循环
- 与 agent 的 Ralph loop（反思-规划-执行循环）原生集成

**为什么有用？**
- 我们之前可能需要自己维护一个"当前目标"状态
- 现在原生支持，不需要自己写状态管理
- 特别适合多轮复杂任务（如周报整理、跨系统数据同步）

**迁移难度：🟢 低** — merge 后直接用 `/goal` 命令即可

---

### 3.2 Post-write Lint — 写入后自动语法检查

**这是什么？**

`write_file` 和 `patch` 工具执行后，v0.13 会自动对生成的文件做语法检查：
- **Python** — `py_compile` 检查语法错误
- **JSON** — `json.loads` 检查格式
- **YAML** — `yaml.safe_load` 检查格式
- **TOML** — `tomllib.loads` 检查格式

**典型场景：**

```
agent: write_file("config.yaml", content)
→ 系统自动检查 config.yaml 的 YAML 语法
→ 如果有语法错误，立即报错并提示修正
→ 不会让错误的文件写入磁盘
```

**为什么有用？**
- 我们之前可能需要自己写 lint 脚本，或者依赖 agent 自己检查
- 现在原生支持，**语法错误在写入时就暴露**，不会"shipping downstream"
- 特别防止 agent 生成格式错误的配置文件、JSON 数据等

**迁移难度：🟢 低** — merge 后自动启用，无需额外配置

### 3.3 `transform_llm_output` 插件钩子

**这是什么？**

新的插件生命周期钩子，允许插件在 LLM 输出进入对话之前 reshape 或 filter 内容。

**典型场景：**
- 内容过滤（屏蔽敏感/不适当内容）
- 上下文窗口缩减（截断冗余输出）
- 格式转换（将 LLM 输出转换为特定格式）

**迁移难度：🟡 中** — 需要写插件实现
