## 二、自我实现功能完整清单

### 2.1 仍在源码中的改动（需保留）

#### A. SOUL.md 加载 — LanceDB 模式（prompt_builder.py）
- **文件：** `agent/prompt_builder.py`
- **状态：** ✅ 已升级为 LanceDB 模式
- **逻辑：** 优先从 LanceDB `souls` 表按 profile 名称读取，fallback 到 `~/.hermes/SOUL.md`
- **用途：** 多 profile 模式下各姐妹加载自己的人格设定
- **与 v0.13 关系：** 自定义功能，v0.13 无原生替代，需保留

#### B. 记忆加载 — LanceDB 模式（memory_tool.py）
- **文件：** `tools/memory_tool.py`
- **状态：** ✅ 已升级为 LanceDB 模式
- **逻辑：** 优先从 LanceDB `memories`/`user` 表读取，fallback 到 USER.md
- **用途：** 替代传统的 MEMORY.md/USER.md 文件读写
- **与 v0.13 关系：** 自定义功能，v0.13 无原生替代，需保留

#### C. agent_registry 表（kanban_db.py）
- **文件：** `hermes_cli/kanban_db.py`
- **状态：** ✅ 保留
- **功能：** 新增 `agent_registry` 表 + CRUD 操作（register_agent/update_agent_status/get_agent/list_agents）
- **用途：** 记录各 agent 的身份、角色、能力、状态，用于 board 可见性和任务路由
- **与 v0.13 关系：** 非原生功能，v0.13 的 Multi-Agent Kanban 可能已有更好方案，升级时需评估

#### D. Snapshot Plugin + Tasks Store
- **文件：** `plugins/memory/snapshot/tasks_store.py` + `tests/agent/test_snapshot_provider.py`
- **状态：** ✅ 保留
- **功能：** SQLite 任务状态追踪（tasks/agents 表），公共看板目录 `~/.hermes/kanban/`，所有 profile 共享
- **与 v0.13 关系：** 非原生功能，v0.13 的 Checkpoints v2 可能覆盖此功能，升级时需评估
