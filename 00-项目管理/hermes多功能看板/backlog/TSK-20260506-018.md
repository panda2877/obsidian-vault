### 一、🎨 UI 组件库选型

#### uView UI 2.x ⭐⭐⭐⭐⭐ 推荐

| 维度 | 说明 |
|------|------|
| **组件丰富度** | 70+ 组件，包含表格、日历、表单、弹窗等企业级组件，管理后台场景足够 |
| **管理后台模板** | 有现成的 uView Admin 模板可参考 |
| **主题定制** | 通过 SCSS 变量全局配置颜色/圆角/字体 |
| **Vue 3 支持** | 2.x 版本已稳定支持 Vue 3 + uni-app |
| **包体积** | 全量引入约 800KB，按需引入可大幅减小 |
| **社区** | GitHub 14k+ Stars，文档完善 |
| **跨端表现** | H5 + 小程序双端兼容，偶有小程序端样式偏差 |

**Demo / 参考：**
- 官方文档：[uView UI 2.x](https://www.uviewui.com/)
- 管理后台模板：[uView Admin](https://gitee.com/umicro/uViewAdmin)

#### uni-ui（DCloud 官方）⭐⭐⭐⭐

| 维度 | 说明 |
|------|------|
| **优点** | DCloud 官方出品，兼容性最好，小程序端性能优 |
| **缺点** | 组件少（约30+），偏移动端，管理后台风格需大量定制，缺表格/树等企业级组件 |
| **结论** | 适合移动端项目，不太适合本项目的管理后台场景 |

**结论：推荐 uView UI 2.x。** 组件丰富度 + 管理后台模板 + 主题定制能力最适合本项目。

### 二、📊 图表库选型

#### uCharts ⭐⭐⭐⭐⭐ 推荐

| 维度 | 说明 |
|------|------|
| **包体积** | 核心包约 150KB，按需引入可更小 |
| **跨端支持** | H5 + 小程序一套代码，原生 canvas 渲染 |
| **图表类型** | 饼图、柱状图、折线图、雷达图等，满足看板需求 |
| **性能** | 小程序端性能优于 ECharts（原生 canvas） |
| **维护** | 插件市场长期维护（`qiun-ucharts`） |
| **缺点** | 自定义能力不如 ECharts，3D/地图不支持 |

**Demo / 参考：**
- 官方文档：[uCharts](https://www.ucharts.cn/)

#### ECharts ⭐⭐⭐⭐

| 维度 | 说明 |
|------|------|
| **优点** | 功能最强，配置丰富，H5 端效果好 |
| **缺点** | 包体积大（完整包约 800KB），小程序端 canvas 渲染性能下降，需适配 |
| **结论** | 杀鸡用牛刀，本项目场景 uCharts 足够 |

#### AntV F2 ⭐⭐⭐

| 维度 | 说明 |
|------|------|
| **优点** | 轻量（约 200KB），阿里出品 |
| **缺点** | uni-app 适配需自定义 canvas 桥接，配置复杂，小程序端文档不完善 |

**结论：推荐 uCharts。** 轻量、跨端一致、性能好，饼图/柱状图/折线图场景完全够用。后续如有复杂需求可条件编译引入 ECharts 补充。

### 三、🖱 拖拽组件选型

#### SortableJS + 条件编译 ⭐⭐⭐⭐⭐ 推荐

| 维度 | 说明 |
|------|------|
| **功能** | 列表拖拽排序、跨列拖拽（看板核心需求） |
| **回调事件** | onStart/onEnd/onAdd/onChange 等丰富事件 |
| **包体积** | 约 30KB，纯 JS 无依赖 |
| **H5 端** | 直接使用 `sortablejs`，表现完美 |
| **小程序端** | 使用 `@uni-helper/sortablejs` 适配版，通过 `#ifdef MP-WEIXIN` 条件编译 |

#### uni-app 内置 movable-view ⭐⭐⭐

| 维度 | 说明 |
|------|------|
| **缺点** | 仅支持单元素拖拽，无法实现看板式列表拖拽排序，不适合任务看板 |

#### vue-draggable-plus ⭐⭐⭐⭐

| 维度 | 说明 |
|------|------|
| **优点** | Vue 3 Composition API 封装，开发体验好 |
| **缺点** | 小程序端适配不成熟，社区较小（1k Stars） |

**结论：推荐 SortableJS + 条件编译。** H5 端直接使用 SortableJS，小程序端用适配版，通过条件编译隔离两套代码。功能完整满足看板拖拽需求。

### 四、⚡ 状态管理

#### Pinia ⭐⭐⭐⭐⭐ 推荐

| 维度 | 说明 |
|------|------|
| **优点** | Vue 3 官方推荐，TS 支持好，体积仅 1KB，API 简洁，支持 DevTools |
| **uni-app 兼容** | 已内置支持 |
| **对比 Vuex 4** | Vuex 4 已进入维护模式，TS 支持弱，API 冗余 |

**结论：推荐 Pinia。**

---

### 五、🌐 网络请求

#### uni.request 封装 ⭐⭐⭐⭐⭐ 推荐

| 维度 | 说明 |
|------|------|
| **优点** | 原生支持，跨端一致性最好，零依赖 |
| **封装方式** | Promise 封装 + 拦截器（Token 注入 + 401 跳转登录） |
| **对比 axios** | axios 需额外适配小程序，包体积 +30KB，本项目 API 简单无需 |

**结论：推荐 uni.request + 自定义封装。**

---

### 六、✨ CSS 方案

#### SCSS ⭐⭐⭐⭐⭐ 推荐

| 维度 | 说明 |
|------|------|
| **优点** | uni-app 内置支持（`<style lang="scss">`），可与 uView 的 SCSS 变量配合主题定制 |
| **管理后台场景** | 变量、嵌套、混合能力适合模块化样式管理 |
| **对比 Tailwind** | Tailwind 在 uni-app 中配置复杂，小程序端 class 名长度受限 |

**结论：推荐 SCSS。**

### 八、配置要点

| 组件 | 配置方式 |
|------|---------|
| **uView UI** | `main.ts` 中 `import uview from 'uview-ui'` → `app.use(uview)` |
| **uCharts** | 组件中 `import uCharts from 'qiun-ucharts'`，使用 canvas 渲染 |
| **SortableJS** | H5 端直接 `import Sortable from 'sortablejs'` |
| **SortableJS (小程序)** | `#ifdef MP-WEIXIN` → `import Sortable from '@uni-helper/sortablejs'` |
| **Pinia** | `main.ts` 中 `import { createPinia } from 'pinia'` → `app.use(createPinia())` |
| **SCSS 主题** | `uni.scss` 中覆盖 uView 的 SCSS 变量（如 `$u-primary: #2979ff`） |
