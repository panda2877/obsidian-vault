# [M3.5] 里程碑进度一览

## 目标
在看板界面上新增里程碑进度一览功能，展示所有里程碑的完成情况和进度。

## 需求
- 展示各里程碑（阶段）的整体进度
- 按里程碑聚合任务数量、完成数、进行中数
- 进度条可视化展示
- 里程碑状态筛选（全部/进行中/已完成）
