# 待办清单系统 - 部署方案 v1.0

> 版本：v1.0
> 日期：2026-04-24

---

## 一、环境说明

| 环境 | 运行方式 |
|------|----------|
| 本地开发 | `./mvnw spring-boot:run`（默认dev） |
| 服务器部署 | `./mvnw spring-boot:run -Pprod` 或 `java -jar app.jar --spring.profiles.active=prod` |

---

## 二、服务器部署步骤

### 1. 拉取最新代码
```bash
cd ~/git-repos/todo-system.git
git pull origin master
```

### 2. 确认生产配置
部署前检查 `application-prod.properties` 中的数据库密码是否正确：
```properties
spring.datasource.url=jdbc:mysql://localhost:3306/todo_db?useSSL=false&serverTimezone=Asia/Shanghai
spring.datasource.username=todo
spring.datasource.password=Pan980523
```

### 3. 构建
```bash
./mvnw clean package -Pprod
```

### 4. 运行
```bash
java -jar target/*.jar --spring.profiles.active=prod
```

### 5. 验证
```bash
curl http://localhost:8080/todo/list
```
