# 待办清单系统 - 银月对接文档 v1.0

> 版本：v1.0
> 日期：2026-04-24

---

## 一、API 地址

```
Base URL: http://localhost:8080
```

银月部署在同一台服务器，直接用 localhost 调用。

---

## 二、接口清单

| 接口 | 方法 | URL | 说明 |
|------|------|-----|------|
| 新增待办 | POST | http://localhost:8080/todo/add | |
| 查询列表 | GET | http://localhost:8080/todo/list | 返回所有待办 |
| 更新待办 | POST | http://localhost:8080/todo/update | 支持更新标题/内容/截止时间/状态 |
| 删除待办 | DELETE | http://localhost:8080/todo/delete/{id} | |
| 查询到期 | GET | http://localhost:8080/todo/due | 查询pending且截止时间<=明天的待办 |

---

## 三、接口详细说明

### 3.1 新增待办 POST /todo/add

**请求：**
```json
{
  "title": "提交周报",
  "content": "发送至部门群",
  "deadline": "2026-04-25T10:00:00"
}
```

**银月调用方式：**
```
POST http://localhost:8080/todo/add
Content-Type: application/json

{
  "title": "提交的标题",
  "content": "可选的描述",
  "deadline": "ISO8601格式的截止时间"
}
```

**响应：**
```json
{ "success": true, "data": { "id": 1 } }
```

---

### 3.2 查询列表 GET /todo/list

**银月调用方式：**
```
GET http://localhost:8080/todo/list
```

**响应：**
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "title": "提交周报",
      "content": "发送至部门群",
      "deadline": "2026-04-25T10:00:00",
      "status": "pending",
      "createdAt": "...",
      "updatedAt": "..."
    }
  ]
}
```

---

### 3.3 更新待办 POST /todo/update

**请求：**
```json
{
  "id": 1,
  "title": "新标题",          # 可选
  "content": "新内容",        # 可选
  "deadline": "...",         # 可选
  "status": "done"           # 可选，pending/done
}
```

**银月调用方式：**
```
POST http://localhost:8080/todo/update
Content-Type: application/json

{
  "id": 待办ID,
  "status": "done"  # 用户说"完成了"时
}
```

---

### 3.4 删除待办 DELETE /todo/delete/{id}

**银月调用方式：**
```
DELETE http://localhost:8080/todo/delete/3
```

**响应：**
```json
{ "success": true }
```

---

### 3.5 查询到期 GET /todo/due

**银月调用方式：**
```
GET http://localhost:8080/todo/due
```

**响应：**
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "title": "提交周报",
      "deadline": "2026-04-25T10:00:00",
      "status": "pending"
    }
  ]
}
```

## 四、对话示例

### 新增
> 你：帮我加一个明天上午10点提交周报的待办
> 银月：
> - title = "提交周报"
> - deadline = 明天上午10点
> - 调用 POST /todo/add
> - 返回确认

### 查询
> 你：我有哪些待办？
> 银月：
> - 调用 GET /todo/list
> - 整理成列表返回给你

### 完成
> 你：周报那个搞定了
> 银月：
> - 从列表中找到"提交周报"的id
> - 调用 POST /todo/update {"id": x, "status": "done"}
> - 返回确认

### 删除
> 你：把test那个删掉
> 银月：
> - 从列表中找到"test"的id
> - 调用 DELETE /todo/delete/{id}
> - 返回确认

### 提醒触发
> 每日8:30，银月主动：
> - 调用 GET /todo/due
> - 拿到到期列表
> - 推送微信消息给你

## 五、注意事项

1. **时间格式**：deadline 必须使用 ISO8601 格式，如 `2026-04-25T10:00:00`
2. **状态值**：只有 `pending` 和 `done` 两种
3. **id 很重要**：更新和删除前必须先从 list 接口获取正确的 id
4. **错误处理**：如果接口返回 `success: false`，读取 `errMsg` 字段并告知用户
