## 一、数据库表结构

```sql
CREATE TABLE todo_list (
    id          BIGINT          AUTO_INCREMENT PRIMARY KEY COMMENT '主键',
    title       VARCHAR(255)    NOT NULL COMMENT '待办标题',
    content     TEXT            DEFAULT NULL COMMENT '详细描述',
    deadline    DATETIME        NOT NULL COMMENT '截止时间',
    status      ENUM('pending','done') DEFAULT 'pending' COMMENT '状态',
    created_at  DATETIME        DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at  DATETIME        DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_deadline (deadline),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='待办清单表';
```

## 二、接口文档

### 2.1 新增待办

- **URL**: `POST /todo/add`
- **Content-Type**: `application/json`

**入参：**
```json
{
  "title": "提交周报",
  "content": "发送至部门群",
  "deadline": "2026-04-25T10:00:00"
}
```

**回参：**
```json
// 成功
{ "success": true, "data": { "id": 1 } }

// 失败
{ "success": false, "errMsg": "标题和截止时间不能为空" }
```

---

### 2.2 查询待办列表

- **URL**: `GET /todo/list`
- **参数**: 无

**回参：**
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "title": "提交周报",
      "content": "发送至部门群",
      "deadline": "2026-04-25T10:00:00",
      "status": "pending",
      "created_at": "2026-04-24T15:00:00",
      "updated_at": "2026-04-24T15:00:00"
    }
  ]
}
```

---

### 2.3 更新待办

- **URL**: `POST /todo/update`
- **Content-Type**: `application/json`

**入参（至少传一个可选字段）：**
```json
{
  "id": 1,
  "title": "提交项目周报",
  "content": "新内容描述",
  "deadline": "2026-04-26T10:00:00",
  "status": "done"
}
```

**回参：**
```json
{ "success": true }

{ "success": false, "errMsg": "缺少待办ID" }
```

---

### 2.4 删除待办

- **URL**: `DELETE /todo/{id}`
- **路径参数**: `id` — 待办主键

**回参：**
```json
{ "success": true }

{ "success": false, "errMsg": "缺少待办ID" }
```

---

### 2.5 查询到期待办（定时提醒专用）

- **URL**: `GET /todo/due`
- **说明**: 查询 `status='pending'` 且 `deadline <= 明天 23:59:59` 的所有待办

**回参：**
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "title": "提交周报",
      "deadline": "2026-04-25T10:00:00",
      "status": "pending"
    }
  ]
}
```

## 三、柳如烟对接方式

柳如烟部署在服务器本地，通过 `http://localhost:8080` 调用 Java API。

### 调用示例

**新增待办：**
```
你：「帮我加一个明天上午10点提交周报的待办」
我：
  1. 解析 → title="提交周报", deadline=明天上午10点
  2. POST http://localhost:8080/todo/add
  3. 返回确认给你
```

**查询到期提醒（每日 8:30）：**
```
我：
  1. GET http://localhost:8080/todo/due
  2. 拿到待办列表
  3. 微信消息推送给你
```
