# 待办清单系统 - 需求文档 v1.1

> 状态：待确认
> 日期：2026-04-24

---

## 背景

现有小程序测试版，需新增个人待办清单功能。
**核心定位：不做前端页面，待办的录入、提醒、状态更新全部由柳如烟（AI助手）接管。**

---

## 系统架构

```
微信小程序（外壳，仅展示）
        ↓
Java REST API 服务（你的服务器 :8080）
        ↓ JDBC
MySQL 数据库（你的服务器本地）
```

柳如烟直接调用 Java API 完成所有待办操作，无需用户手动操作界面。

---

## 功能清单

### ① 待办管理（CRUD）

柳如烟通过 REST API 完整操作，用户无需接触界面。

| 接口 | 方法 | 说明 |
|------|------|------|
| `/todo/add` | POST | 新增待办 |
| `/todo/list` | GET | 查询所有待办 |
| `/todo/update` | POST | 更新待办（修改内容/状态/截止时间） |
| `/todo/delete/{id}` | DELETE | 删除待办 |

### ② 定时提醒

- 触发时间：每日 8:30
- 触发方式：柳如烟定时任务，调用 `/todo/due` 查询当天到期待办
- 推送方式：微信消息直接通知用户
- 提醒内容：到期待办的标题 + 截止时间

### ③ 用户交互示例

**新建：**
> 你：「帮我加一个明天上午10点提交周报的待办」
> 柳如烟：「好的，已添加『提交周报』，截止时间：明天上午10点 ✓」

**查询：**
> 你：「我有哪些待办？」
> 柳如烟：「你目前有3条待办：① 提交周报（明天10:00）② ...」

**更新：**
> 你：「周报那个搞定了」
> 柳如烟：「已完成 ✓」

**提醒（每日 8:30 自动推送）：**
> 柳如烟：「早！今日有2条待办到期：① 提交周报（10:00）② ...」

## 数据库设计

**表名：`todo_list`**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键，自增 |
| title | VARCHAR(255) | 待办标题（必填） |
| content | TEXT | 详细描述（可选） |
| deadline | DATETIME | 截止时间（必填） |
| status | ENUM | pending / done |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

## API 详细设计

### POST /todo/add

**请求：**
```json
{
  "title": "提交周报",
  "content": "发送至部门群",
  "deadline": "2026-04-25T10:00:00"
}
```

**响应：**
```json
{
  "success": true,
  "data": { "id": 1 }
}
```

### GET /todo/list

**请求参数：**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| status | string | 否 | 筛选状态：`pending` / `done` |
| deadline | string | 否 | 截止日期，格式：`YYYY-MM-DD`，筛选该日期及之前的待办 |

**业务规则：**
- `status` 不传时：默认返回全部（pending + done）
- `status=pending`：只返回未完成的待办
- `status=done`：只返回已完成的待办
- `deadline` 不传时：不过滤日期，返回所有符合状态的待办
- `deadline` 传值时：返回截止日期 <= 传入值的待办
- `status` + `deadline` 同时传时，两个条件同时生效（AND）

**柳如烟调用方式：**
```
GET http://localhost:8080/todo/list
GET http://localhost:8080/todo/list?status=pending
GET http://localhost:8080/todo/list?status=done
GET http://localhost:8080/todo/list?deadline=2026-04-25
GET http://localhost:8080/todo/list?status=pending&deadline=2026-04-25
```

**响应：**
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "title": "提交周报",
      "content": "发送至部门群",
      "deadline": "2026-04-25T10:00:00",
      "status": "pending",
      "createdAt": "...",
      "updatedAt": "..."
    }
  ]
}
```

### POST /todo/update

**请求：**
```json
{
  "id": 1,
  "status": "done"
}
```

**响应：**
```json
{
  "success": true
}
```

### DELETE /todo/{id}

**响应：**
```json
{
  "success": true
}
```

### GET /todo/due（用于定时提醒）

**响应：**
```json
{
  "success": true,
  "data": [
    { "id": 1, "title": "提交周报", "deadline": "2026-04-25T10:00:00", "status": "pending" }
  ]
}
```
