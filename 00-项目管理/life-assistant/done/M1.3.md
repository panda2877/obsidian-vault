# [M1.3] [开发] 后端路由框架搭建

## 目标
新增 /api/life/* 路由组，挂载认证中间件

## 完成情况

- ✅ 创建 `backend/routes/life.js` — 注册 14 个 API 端点
  - POST `/api/life/auth/bind` — 设备绑定（无需鉴权）
  - GET `/api/life/auth/check` — Token 验证（无需鉴权）
  - GET/POST/PUT/DELETE `/api/life/finance[/:id]` — 记账 CRUD（需鉴权）
  - GET `/api/life/categories` — 分类列表（需鉴权）
  - GET/POST/PUT/DELETE `/api/life/todo[/:id]` — 待办 CRUD（需鉴权）
- ✅ 创建 `backend/middleware/lifeAuth.js` — JWT 鉴权中间件（401 拦截 + 过期/无效/缺失三种错误码）
- ✅ 创建 `backend/controllers/lifeAuthController.js` — 鉴权控制器（bind + check）
- ✅ 所有路由挂载到 Express 主路由 `app.use('/api/life', lifeRouter)`
