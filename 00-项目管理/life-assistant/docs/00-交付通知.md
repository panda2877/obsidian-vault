### 2. 数据库设计需求

| 表名 | 说明 |
|------|------|
| `finance_records` | 记账记录（收支流水） |
| `finance_categories` | 记账分类（含系统预设） |
| `todo_tasks` | 待办任务 |

**关键字段**:
- 所有表需包含 `user_id` 外键（数据隔离）
- 所有表需包含 `sync_status` 字段（同步状态：local/synced/pending）

### 3. API 接口需求

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/life/finance` | 创建记账 |
| GET | `/api/life/finance` | 获取记账列表 |
| PUT | `/api/life/finance/:id` | 更新记账 |
| DELETE | `/api/life/finance/:id` | 删除记账 |
| GET | `/api/life/categories` | 获取分类列表 |
| POST | `/api/life/todo` | 创建待办 |
| GET | `/api/life/todo` | 获取待办列表 |
| PUT | `/api/life/todo/:id` | 更新待办 |
| DELETE | `/api/life/todo/:id` | 删除待办 |
