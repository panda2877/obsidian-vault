## 📌 一、背景与目标

### 业务背景
老大需要一个跨平台（手机 H5 + 网页）的生活助手应用，涵盖记账、待办等日常功能。现有 Hermes Dashboard 面板系统已具备跨平台能力（uni-app + Express BFF），在此基础上新增生活助手模块，而非另起新项目。

### 核心目标
1. **融合现有面板系统** — 在 Hermes Dashboard 中新增"生活"Tab，复用现有架构
2. **云端同步** — 所有数据通过 API 操作，手机端 H5 实时访问
3. **便捷鉴权** — 单用户 + 长效 JWT Token 绑定设备
4. **MVP 可上线** — M1 搭好基建，M2/M3 功能完成后即可发布

### 成功标准
- [ ] 新增"生活"Tab，与现有4个Tab并列（第5个Tab）
- [ ] 所有生活助手数据通过 API 操作，云端持久化
- [ ] 手机端首次输入 Token 绑定设备，后续自动登录
- [ ] 手机端 H5 网页版可正常访问
- [ ] 数据实时通过 API 同步（不依赖离线缓存）

## 🔀 四、业务流程

### M1 主流程（用户数据操作）

```
用户打开手机 H5 / 网页端
    ↓
检测是否有已绑定的 Token
    ├─ 有 → 自动登录，进入"生活"Tab
    └─ 无 → 显示绑定页面（输入 Token）
              ↓
        服务端验证 Token → 绑定设备标识
              ↓
        生成设备会话 → 进入"生活"Tab
    ↓
前端请求数据 → API 携带 Token
    ↓
后端验证 Token → 提取用户身份
    ↓
查询数据（单用户，无需 user_id 过滤）
    ↓
返回数据 → 前端渲染
    ↓
用户操作（增删改）→ API 写入 → 云端持久化
```

### 离线场景（M1 阶段）
```
用户离线 → 操作不可用
    ↓
显示离线提示："当前无网络连接"
    ↓
恢复网络 → 正常操作
```

### 多设备绑定流程
```
管理员（老大）在服务器生成长效 Token
    ↓
新设备打开 → 提示输入 Token
    ↓
输入 Token → 服务端验证 → 记录设备标识
    ↓
绑定成功 → 正常使用
```

## 💾 五、数据概念

### 核心实体

#### 设备绑定表（device_bindings）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键（自增） |
| token_hash | VARCHAR(64) | Token 哈希值 |
| device_id | VARCHAR(100) | 设备唯一标识 |
| device_name | VARCHAR(100) | 设备名称（可选） |
| last_login_at | TIMESTAMP | 最后登录时间 |
| created_at | TIMESTAMP | 绑定时间 |

#### 记账表（finance_records）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键（自增） |
| type | TEXT | 收支类型：in/out |
| amount | REAL | 金额 |
| category_id | INTEGER | 分类ID（外键） |
| note | TEXT | 备注 |
| record_date | TEXT | 记账日期（ISO格式） |
| created_at | TEXT | 创建时间 |
| updated_at | TEXT | 更新时间 |

#### 分类表（finance_categories）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键（自增） |
| name | TEXT | 分类名称 |
| type | TEXT | 收支类型：in/out |
| icon | TEXT | 图标标识 |
| sort_order | INTEGER | 排序 |

#### 待办表（todo_tasks）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键（自增） |
| title | TEXT | 任务标题 |
| description | TEXT | 详细描述 |
| category | TEXT | 分类标签 |
| priority | TEXT | 优先级：low/normal/high |
| status | TEXT | 状态：todo/doing/done |
| due_date | TEXT | 截止日期（ISO格式） |
| created_at | TEXT | 创建时间 |
| updated_at | TEXT | 更新时间 |

### 数据关系
- 单用户模式，所有表无需 user_id 字段
- `finance_categories` 1:N `finance_records`（一个分类多条记账）
