## 📌 一、背景与目标

### 业务背景
老大需要一个跨平台（手机+网页）的生活助手应用，涵盖记账、待办等日常功能。现有 Hermes Dashboard 面板系统已具备跨平台能力（uni-app + Express BFF），希望在此基础上新增生活助手模块，而非另起新项目。

### 核心目标
1. **融合现有面板系统** — 在 Hermes Dashboard 中新增"生活"Tab，复用现有架构
2. **云端同步优先** — M1 必须建立完整的云端同步框架，确保手机端可用
3. **用户空间隔离** — 多用户数据隔离，支持未来扩展
4. **MVP 可上线** — M2/M3 完成后即可发布"能用"的版本

### 成功标准
- [ ] 新增"生活"Tab，与现有4个Tab并列
- [ ] 所有生活助手数据通过 API 操作，支持云端持久化
- [ ] 用户登录后可看到自己的数据（多用户隔离）
- [ ] 手机端 H5 可正常访问
- [ ] 数据可离线缓存，网络恢复后自动同步

## 🔀 四、业务流程

### M1 主流程（用户数据操作）

```
用户登录 → JWT Token 获取
    ↓
用户进入"生活"Tab
    ↓
前端请求数据 → API 携带 Token
    ↓
后端验证 Token → 提取 user_id
    ↓
查询用户数据（WHERE user_id = ?）
    ↓
返回数据 → 前端渲染
    ↓
用户操作（增删改）→ API 写入 → 云端持久化
    ↓
本地缓存更新（同步状态：已同步）
```

### 离线场景流程

```
用户离线 → 操作数据
    ↓
写入本地缓存（IndexedDB）
    ↓
标记同步状态：pending
    ↓
网络恢复 → 检测 pending 数据
    ↓
批量同步 → API 写入云端
    ↓
更新本地同步状态：已同步
```

## 💾 五、数据概念

### 核心实体

#### 用户表（users）— 复用或扩展
| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| username | VARCHAR(50) | 用户名 |
| password_hash | VARCHAR(255) | 密码哈希 |
| created_at | TIMESTAMP | 创建时间 |

#### 记账表（finance_records）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| user_id | UUID | 用户ID（外键） |
| type | ENUM(in, out) | 收支类型 |
| amount | DECIMAL(10,2) | 金额 |
| category_id | UUID | 分类ID（外键） |
| note | VARCHAR(255) | 备注 |
| record_date | DATE | 记账日期 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |
| sync_status | ENUM(local, synced, pending) | 同步状态 |

#### 分类表（finance_categories）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| user_id | UUID | 用户ID（外键，NULL=系统预设） |
| name | VARCHAR(50) | 分类名称 |
| type | ENUM(in, out) | 收支类型 |
| icon | VARCHAR(20) | 图标标识 |
| is_system | BOOLEAN | 是否系统预设 |

#### 待办表（todo_tasks）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| user_id | UUID | 用户ID（外键） |
| title | VARCHAR(200) | 任务标题 |
| description | TEXT | 详细描述 |
| category | VARCHAR(50) | 分类标签 |
| priority | ENUM(low, normal, high) | 优先级 |
| status | ENUM(todo, doing, done) | 状态 |
| due_date | DATE | 截止日期 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |
| sync_status | ENUM(local, synced, pending) | 同步状态 |

### 数据关系
- `users` 1:N `finance_records`（一个用户多条记账）
- `users` 1:N `finance_categories`（一个用户多个分类）
- `users` 1:N `todo_tasks`（一个用户多个待办）
- `finance_categories` 1:N `finance_records`（一个分类多条记账）
