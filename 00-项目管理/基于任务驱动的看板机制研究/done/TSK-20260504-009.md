## 任务目标

当任务需要人工审批时，通过看板机制通知人类，等待人工介入后继续。

## 简化方案（替代原自建 Review Gate）

原生 kanban 已有等效机制：

| 原计划 | 替代方案 |
|--------|----------|
| 自建 Review Gate 触发审批通知 | 原生 `kanban_block` 工具 — agent 调用后任务进入 `blocked`，人类可通过评论或直接改看板状态解除 |
| 自建 Web 看板审批 UI | 原生 `kanban_comment` + 看板拖拽 |

### 实现方式

Agent 需要人工确认时，调用：

```python
kanban_block(task_id="<id>", reason="需要人工审批：XXX")
```

人类看到 blocked 任务后：
1. 在看板 UI 中拖拽到 `running` 解除阻塞，或
2. 通过 `kanban_comment` 回复审批意见

## 验收标准

- [x] Agent 调用 `kanban_block` 后任务进入 `blocked` 状态
- [x] 人类解除阻塞后任务可继续执行
- [x] 审批意见通过 comment 记录
