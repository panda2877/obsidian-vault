## 任务目标

在 `agent:end` 事件触发时，写入最终 checkpoint（phase='wrapping'），标记任务完成并归档上下文。

## 触发时机

`agent:end` 事件 → `write_checkpoint(phase='wrapping')`

注意：原方案写 `phase='done'`，整合方案后改为 `phase='wrapping'`，表示收尾阶段。

## 调用接口

```python
snapshot_provider.write_checkpoint(
    task_id="<任务ID>",
    phase="wrapping",
    summary="<最终交付摘要>",
    findings=["<最终发现>"],
    blockers=[],
    next_steps=[],
    mission_id="<mission_id>",
)
```

