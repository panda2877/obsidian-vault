## 目标

修复看板系统的三个结构性断层：

1. **无项目名字段** → 只能按路径查，无法按"项目名称"索引
2. **无文件路径字段** → db 不知道卡片在哪，跨目录就断联
3. **根看板不同步** → 项目总览 md 和 db 不同步

同时清理以下废弃任务：
- TSK-20260504-005 FastAPI 后端（已废弃）
- TSK-20260504-006 React 前端（已废弃）
- TSK-20260504-010 WebSocket 推送（已废弃）

## 验收标准

- [x] tasks 表增加 project_name 字段
- [x] tasks 表增加 file_path 字段
- [x] sync.py 支持多项目根目录看板同步
- [x] 废弃任务归档（status→archived）
- [x] default 看板总览 md 创建并同步状态
