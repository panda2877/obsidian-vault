## 任务目标

在 `run_agent.py` 主循环中集成 `on_task_start` hook，当 agent 开始处理任务时，调用 `snapshot_provider.write_checkpoint(phase='exploring')`。

## 触发时机

agent 首次开始处理一个任务时（session 中第一次认领任务）

## 调用接口

```python
snapshot_provider.write_checkpoint(
    task_id="<任务ID>",
    phase="exploring",
    summary="<任务目标一句话描述>",
    findings=[],
    blockers=[],
    next_steps=[],
    mission_id="<mission_id>",
)
```

## 验收标准

- [ ] `run_agent.py` 中存在 `on_task_start` hook 调用点
- [ ] 任务开始时 checkpoint 写入 SQLite
- [ ] 新会话启动时 system prompt 包含 `## 阶段上下文 [来自 Checkpoint]`
