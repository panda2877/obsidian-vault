# 看板文件范式

> 本文件定义了基于 Obsidian + SQLite 的看板机制中，任务文件的标准化格式。
> 每个物理任务对应一个 Markdown 文件，文件内容即任务的完整上下文。

---

## 一、目录结构规范

```
基于任务驱动的看板机制研究/
├── .kanban/                      # 元数据目录（SQLite 等）
│   ├── kanban.db                 # SQLite 数据库
│   └── config.yaml              # 看板配置
├── 看板文件范式.md               # 本文件
├── 任务-2026-05/                 # 按月组织的任务文件
│   ├── inbox/                    # Inbox（未开始）
│   │   └── TSK-20260504-001.md
│   ├── in-progress/              # 进行中
│   │   └── TSK-20260504-002.md
│   ├── review/                   # Review
│   │   └── TSK-20260504-003.md
│   └── done/                     # 已完成
│       └── TSK-20260504-000.md
└── templates/                    # 模板目录
    └── task-template.md          # 任务模板
```

**命名规范**：`TSK-{date}-{seq}.md`，例如 `TSK-20260504-001.md`

## 三、Checkpoint 格式说明

每个 checkpoint 块包含以下字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| `阶段` | 是 | `exploring` \| `implementing` \| `testing` \| `wrapping` |
| `执行者` | 是 | agent profile 名称 |
| `摘要` | 是 | 本阶段做了什么（1-3 句话） |
| `发现` | 否 | 本阶段发现的重要信息 |
| `阻塞` | 否 | 当前卡点，以 `⚠️` 标记 |
| `下一步` | 否 | 待办列表，对应下一个阶段的任务 |

## 四、SQLite Schema（参考）

```sql
-- 任务索引表（可选，用于快速查询）
CREATE TABLE IF NOT EXISTS task_index (
  id TEXT PRIMARY KEY,
  file_path TEXT NOT NULL,
  status TEXT NOT NULL,
  priority TEXT NOT NULL,
  assignee TEXT,
  mission_id TEXT,
  updated_at TEXT NOT NULL
);

-- Checkpoint 历史表（用于 timeline 视图）
CREATE TABLE IF NOT EXISTS checkpoints (
  id TEXT PRIMARY KEY,
  task_id TEXT NOT NULL,
  phase TEXT NOT NULL,
  summary TEXT,
  blockers TEXT,
  next_steps TEXT,
  agent_id TEXT,
  created_at TEXT NOT NULL
);
```

## 五、触发 Hook 与文件写入的对应关系

| Hook 事件 | 触发的文件操作 | 写入的内容 |
|-----------|---------------|------------|
| `on_task_start` | 创建任务文件 + 写入初始 checkpoint | phase=exploring, 任务目标 |
| `on_phase_change` | 追加新的 checkpoint 块 | 当前阶段的 findings/blockers/next_steps |
| `on_task_done` | 移动文件到 done/ 目录 + 追加 final checkpoint | phase=wrapping, 最终摘要 |

## 六、与 Snapshot 机制的对应

| Snapshot 字段 | 看板文件对应 |
|---------------|-------------|
| `task_goals` | Frontmatter `title` + `## 任务目标` |
| `checklist` | `## 检查点历史` 中的 `下一步` 列表 |
| `assignments` | Frontmatter `assignee` |
| `missing_info` | Checkpoint 块中的 `阻塞` 字段（⚠️ 标记） |
| `messages` | `## 当前工作区`（实时追加） |
