## 任务目标

定期检查 `in_progress` 状态超过阈值（如 2 小时）的任务，向人类发送超时提醒，并提供重启/转交选项。

## 实现方案

使用 Hermes cronjob，定期执行：

```sql
SELECT * FROM tasks
WHERE status = 'in_progress'
AND updated_at < datetime('now', '-2 hours');
```

检测到超时任务后：
1. 写入 checkpoint（phase='blocked', blockers=['⚠️ 任务超时，可能已挂起'])
2. 发送飞书/微信超时提醒
3. 提供 `/transfer-task {task_id}` 命令转交给其他 agent

## 配置项

```yaml
kanban:
  watchdog:
    timeout_hours: 2
    check_interval_minutes: 30
    notify_channels:
      - feishu
```

## 验收标准

- [ ] cron 看门狗正确检测超时任务
- [ ] 超时任务写入 blocked checkpoint
- [ ] 人类收到超时提醒
