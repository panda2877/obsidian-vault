## 任务目标

将自建 tasks.db 迁移到原生 `~/.hermes/kanban.db`，复用原生 schema 和并发机制。

## 背景变更

原任务「补全 tasks 表」已废弃 — 原生 `kanban_db.py` 已有完整 tasks 表，无需自建。

本任务改为：在原生 kanban.db 上追加自建所需字段（mission_id），并创建 Checkpoint + Agent 表。

## 操作步骤

### Step 1：修改原生迁移函数

文件：`hermes_cli/kanban_db.py`

在 `_migrate_add_optional_columns()` 中追加：

```python
if "mission_id" not in cols:
    conn.execute("ALTER TABLE tasks ADD COLUMN mission_id TEXT")
```

### Step 2：创建自建扩展表

在原生 kanban.db 中创建：

```sql
CREATE TABLE IF NOT EXISTS checkpoints (
    id          TEXT PRIMARY KEY,
    task_id     TEXT NOT NULL,
    phase       TEXT NOT NULL,
    summary     TEXT,
    blockers    TEXT,
    next_steps  TEXT,
    agent_id    TEXT,
    created_at  TEXT NOT NULL,
    FOREIGN KEY (task_id) REFERENCES tasks(id)
);

CREATE TABLE IF NOT EXISTS agent_registry (
    id            TEXT PRIMARY KEY,
    profile       TEXT NOT NULL UNIQUE,
    name          TEXT NOT NULL,
    role          TEXT NOT NULL DEFAULT 'generalist',
    capabilities  TEXT NOT NULL DEFAULT '[]',
    status        TEXT NOT NULL DEFAULT 'idle',
    registered_at TEXT NOT NULL
);
```

### Step 3：验证

```bash
sqlite3 ~/.hermes/kanban.db ".schema tasks"
sqlite3 ~/.hermes/kanban.db ".tables"
sqlite3 ~/.hermes/kanban.db ".schema checkpoints"
```
