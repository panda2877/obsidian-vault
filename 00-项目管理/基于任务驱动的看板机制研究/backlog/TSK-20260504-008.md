## 任务目标

建立 Agent 注册机制，记录哪个 agent 正在处理哪个任务，避免多个 agent 并发处理同一任务。

## 实现思路

在 SQLite 中新增 `agent_registry` 表：

```sql
CREATE TABLE agent_registry (
  agent_id    TEXT PRIMARY KEY,
  task_id     TEXT,
  claimed_at  TEXT,
  FOREIGN KEY (task_id) REFERENCES tasks(id)
);
```

- agent 认领任务时：`INSERT OR REPLACE INTO agent_registry (agent_id, task_id, claimed_at) VALUES (?, ?, ?)`
- 任务状态变更时：清除对应 `task_id` 的 registry 记录
- 新 agent 拉取任务时：检查 `agent_registry` 避免重复认领

## 验收标准

- [ ] `agent_registry` 表创建成功
- [ ] agent 认领任务时正确写入 registry
- [ ] 任务完成时 registry 记录清除
- [ ] 并发认领时只有第一个成功
