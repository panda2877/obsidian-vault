## 任务目标

实现 FastAPI 后端，提供任务和 checkpoint 的读写接口，供前端看板调用。

## API 设计

### 任务接口

| Method | Path | 说明 |
|--------|------|------|
| GET | `/api/tasks` | 列出任务（支持 status/assignee/mission_id 过滤） |
| POST | `/api/tasks` | 创建任务 |
| GET | `/api/tasks/{task_id}` | 获取任务详情 |
| PATCH | `/api/tasks/{task_id}` | 更新任务（状态/优先级/负责人） |
| DELETE | `/api/tasks/{task_id}` | 删除任务 |

### Checkpoint 接口

| Method | Path | 说明 |
|--------|------|------|
| GET | `/api/tasks/{task_id}/checkpoints` | 获取任务的 checkpoint 列表（时间正序） |
| POST | `/api/tasks/{task_id}/checkpoints` | 写入 checkpoint |
| GET | `/api/checkpoints/latest?mission_id=xxx` | 获取某 mission 的最新 checkpoints |

## 认证

`isAuthenticated` middleware（同现有 hermes-tasks API）

## 验收标准

- [ ] 所有 API 接口可正常调用
- [ ] 任务状态变更正确写入 SQLite
- [ ] checkpoint 正确关联 task_id
