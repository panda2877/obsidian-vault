## 状态变更

**❌ 已废弃 — 原生 v0.12 已提供等效能力**

| 原计划 | 替代方案 |
|--------|----------|
| 自建 FastAPI 后端 | 原生 `hermes kanban` CLI |
| 自建 CRUD 接口 | 原生 `kanban_tools.py`（7个工具） |
| checkpoint API | 自建 Checkpoint 表（独立维护） |

## 替代方案详情

### 原生 CLI

```bash
hermes kanban create "标题" --assignee xingruyin
hermes kanban list --status running
hermes kanban show <task_id>
hermes kanban complete <task_id> --summary "..."
```

### 原生 Agent Tools

Agent 可直接调用 `kanban_tools.py` 中的 7 个工具：
- `kanban_show` — 读取任务完整状态
- `kanban_complete` — 标记完成
- `kanban_block` — 阻塞等待人工
- `kanban_heartbeat` — 长任务保活
- `kanban_comment` — 追加评论
- `kanban_create` — 创建子任务
- `kanban_link` — 添加依赖

### 自建 Checkpoint API

Checkpoint 表仍在自建 `plugins/memory/snapshot/checkpoint_store.py`，独立维护，无需 API 层。
