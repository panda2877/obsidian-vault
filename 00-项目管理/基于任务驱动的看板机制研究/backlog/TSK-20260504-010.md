## 任务目标

通过 WebSocket 实时推送任务状态变更，让所有在线 agent 和人类看板实例同步感知任务变化。

## 推送事件

| 事件 | 触发时机 | 载荷 |
|------|---------|------|
| `task:created` | 新建任务 | `{task: HubTask}` |
| `task:moved` | 任务列间移动 | `{taskId, from, to, task}` |
| `task:updated` | 任务信息更新 | `{taskId, updates}` |
| `task:completed` | 任务完成 | `{taskId, task}` |
| `checkpoint:created` | 新 checkpoint | `{checkpoint}` |

## 实现方案

在 FastAPI 后端接入 WebSocket，支持：
- agent 连接时订阅特定 mission_id
- 任务变更时广播到所有订阅者

## 验收标准

- [ ] WebSocket 连接建立成功
- [ ] 任务状态变更实时推送到所有连接客户端
- [ ] agent 可订阅特定 mission_id
