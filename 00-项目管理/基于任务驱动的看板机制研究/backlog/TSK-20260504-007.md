## 任务目标

当 Web 看板状态变更时，同步更新对应 Obsidian MD 文件的 frontmatter；反之，人类在 Obsidian 中修改 frontmatter 时，同步到 SQLite。

## 同步规则

### SQLite → Obsidian（Web 看板变更时）

| SQLite 字段 | Obsidian frontmatter |
|------------|---------------------|
| `status` | `status` |
| `priority` | `priority` |
| `assignee` | `assignee` |
| `updated_at` | `updated` |

### Obsidian → SQLite（人类编辑时）

| Obsidian frontmatter | SQLite 字段 |
|---------------------|------------|
| `status` | `status` |
| `priority` | `priority` |
| `assignee` | `assignee` |

## 文件路径映射

```
任务 ID: TSK-20260504-001
→ Obsidian 文件: {vault}/00-项目管理/基于任务驱动的看板机制研究/{status}/TSK-20260504-001.md
```

## 实现方案

使用文件监视器（fswatch / inotifywait）监控 `.kanban/` 目录，检测到变更后解析 frontmatter 并更新 SQLite。

## 验收标准

- [ ] Web 看板拖拽后 Obsidian 文件 frontmatter 同步更新
- [ ] Obsidian 中修改 frontmatter 后 SQLite 同步更新
- [ ] 目录移动（in-progress → done）正确处理
