## 任务目标

在 `run_agent.py` 主循环中集成 `on_task_done` hook，当任务移至 `done` 列时，写入最终 checkpoint（phase='done'），并归档任务上下文。

## 触发时机

任务状态变更为 `done` 时

## 调用接口

```python
snapshot_provider.write_checkpoint(
    task_id="<任务ID>",
    phase="done",
    summary="<最终交付摘要>",
    findings=["<最终发现>"],
    blockers=[],  # 无阻塞表示完成
    next_steps=[],  # 无下一步表示完成
    mission_id="<mission_id>",
)
```

## 额外动作

- [ ] 将任务文件从 `in-progress/` 目录移动到 `done/` 目录
