## 任务目标

当任务进入 `review` 列时，自动触发人工审批通知，提醒人类进行验收。

## 触发时机

`PATCH /api/tasks/{task_id}` 将 status 更新为 `review`

## 通知方式

- Web 看板内：在任务卡片上显示待审批 Badge
- 飞书/微信：发送审批通知消息

## 审批动作

人类审批通过 → 任务移至 `done`
人类审批拒绝 → 任务退回 `in_progress`，附拒绝理由

## 实现方案

在 `kanban-board.tsx` 的 `moveTask` 中，检测 `nextColumn === 'review'` 时：

```typescript
if (nextColumn === 'review') {
  addApproval({
    agentId: task.agentId ?? 'unassigned',
    agentName: assignee,
    action: `Review task: ${task.title}`,
    context: task.description,
    source: 'agent',
  });
}
```

## 验收标准

- [ ] 任务进入 review 列时触发审批通知
- [ ] 人类审批通过后任务正确移至 done
- [ ] 审批拒绝时任务退回 in_progress
